# Configuración compartida de `Niva-org`

Este repositorio es la configuración por defecto de la organización: plantillas de issue y de PR, `CODEOWNERS` y política de seguridad. GitHub lo lee automáticamente para todos los repositorios que no definan los suyos.

| Archivo | Para qué |
|---|---|
| `.github/PULL_REQUEST_TEMPLATE.md` | checklist de PR (incluye el checklist de diseño de 02 §12) |
| `.github/ISSUE_TEMPLATE/` | bug, propuesta, cambio de especificación y pregunta abierta |
| `CODEOWNERS` | dueño por defecto de todos los repositorios |
| `SECURITY.md` | cómo reportar una vulnerabilidad |

Reglas del proyecto: `Niva-org/platform/CLAUDE.md`. Especificación: `Niva-org/platform/docs/spec/`.

Este repositorio debe ser público porque GitHub solo toma las plantillas de organización desde un repositorio público llamado `.github`. No publiques aquí código, datos ni secretos.
